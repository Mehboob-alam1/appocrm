# Niche + city selection (Phase 0)

Pick **one profession** and **one city** (or one metro). You are not building “for all small businesses.”

---

## Step 1 — Shortlist professions

From the product plan, ranked by opportunity:

1. Independent tradesperson (AC, appliance, electrician, plumber)
2. Solo tutor / small coaching center
3. Small shop / salon (repeat customers, credit)
4. ~~Insurance / loan / tele-sales agent~~ — skip initially (NeoDove territory)
5. Freelancer / consultant — viable globally; often less “call-after-every-job” than trades

Add your own if you have access (e.g. wedding photographer, pest control solo operator).

---

## Step 2 — Score each option (1 = low, 5 = high)

Copy this table for each candidate **profession + city** pair:

| Criterion | Score 1–5 | Notes |
|-----------|-----------|--------|
| **You can reach them** — you speak the language, know the city, or have friends in that trade | | |
| **Phone-first workflow** — job details happen on calls, not email | | |
| **Follow-up pain** — missed callbacks = lost money | | |
| **Solo or 1–2 people** — not a 10-seat call center | | |
| **WhatsApp-heavy** — quotes, photos, “call me” | | |
| **Community density** — can you find 3–5 active online groups? | | |
| **Android majority** — target users on Android phones | | |
| **Willingness to try new apps** — not locked into enterprise CRM | | |

**Total / 40:** _____

Repeat for 2–3 pairs. Highest total wins **unless** one criterion is 1–2 on “reach them” or “community density”—those are blockers.

---

## Step 3 — Write the one-line target

Template:

> **I am validating Appomatrix for:** `[profession]` **in** `[city/region]` **who** run jobs via phone + WhatsApp and track follow-ups in their head, notebook, or chat history.

Example (illustration only—replace with yours):

> I am validating Appomatrix for: independent AC and appliance repair technicians in Bengaluru who quote on-site and juggle 5–15 open jobs per week.

---

## Step 4 — Anti-goals (who this is NOT for)

Check all that apply for your niche; if many apply, reconsider:

- [ ] Teams with dedicated telecallers and auto-dialers
- [ ] Users who live inside Salesforce/Zoho all day
- [ ] Businesses with zero follow-up (pure walk-in only, no callbacks)
- [ ] Users who refuse to install anything outside WhatsApp

## If you are stuck choosing

Run a **48-hour probe**: join one group each for your top two niches (same city). Post the neutral “how do you track follow-ups?” question from [outreach-templates.md](./outreach-templates.md). Whichever gets **more honest replies and DMs** wins—data beats guessing.
