# Interview guide (10–15 minutes)

Use for WhatsApp chat or phone. Goal: **pain, current workflow, willingness to try**—not feature brainstorming.

---

## Before the call

- [ ] Confirm language and time
- [ ] Say you’ll take notes (no recording unless they agree)
- [ ] Open [validation-log.csv](./validation-log.csv) row ready

---

## Opening

> I’m learning how [profession] owners run follow-ups. There are no right answers—your real routine is what helps.

---

## Core questions (pick all; skip if answered early)

### Current workflow

1. Walk me through **yesterday**: a customer call or WhatsApp—what did you do right after?
2. Where is that information **now**? (head, notebook, phone notes, WhatsApp chat, Excel, app name)
3. How many **open** jobs or follow-ups do you juggle in a typical week?

### Pain

4. When did you last **forget** a follow-up or quote? What happened?
5. What’s hardest: finding old chats, remembering dates, or knowing who paid?

### Tools

6. Have you tried any app or CRM? Why did you stop or never start?
7. Would you pay for anything today? How much feels fair **per month** in local currency? (Optional—many will say zero; note it.)

### Concept reaction (short pitch)

8. “After a call, one tap voice note → text saved on contact → home screen shows who to follow up today—all on phone, no cloud.” **What’s your first reaction?** (Useful / useless / missing X)
9. What would make you **not** install it? (trust, time, language, storage, “wife handles phone,” etc.)

### Close

10. If we build a **rough Android test** in a few weeks, can I message you on WhatsApp once to try it?
11. Anyone else like you I should talk to? (referral)

---

## Listen for (tag in notes)

| Tag | Meaning |
|-----|---------|
| `PAIN_HIGH` | Lost money / angry customer from forgotten follow-up |
| `PAIN_MED` | Inconvenient search in WhatsApp |
| `PAIN_LOW` | “Customers call me back” |
| `WA_PRIMARY` | WhatsApp is the system of record |
| `NOTEBOOK` | Physical diary |
| `TEAM_CRM` | Wrong segment (NeoDove-style) |
| `INTEREST_YES` | Would try beta |
| `INTEREST_MAYBE` | Needs proof / trust |
| `INTEREST_NO` | Clear rejection |

---

## After

- Fill CSV row within 1 hour while memory is fresh
- Paste **one verbatim quote** (with permission) into notes—gold for landing page later
- If `INTEREST_YES`, mark `waitlist_yes`
