# Phase 6 — Scale decision (month 6+)

Choose **one** path based on data, not ego.

## Option A — Dominate one niche (recommended)

- Same profession + region until you’re the default name
- Example: “AC techs in Bangalore use Appomatrix”
- Low burn, strong word-of-mouth

## Option B — Adjacent professions

- Same city, similar workflow (plumber → electrician)
- Reuse product; change marketing only
- Risk: diluted support if too many segments at once

## Option C — Team / call-center features

- Only if users **pay** and explicitly ask
- Competes with NeoDove/TeleCRM — different company
- Requires multi-user sync, roles, dialer integrations

## Kill criteria

Stop or pivot if after 6 months:

- &lt;50 weekly actives in target niche
- No organic referrals
- Voice feature unused (&lt;20% of WAU)
