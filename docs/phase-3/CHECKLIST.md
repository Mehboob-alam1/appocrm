# Phase 3 — Public launch (your checklist)

The repo is Play-ready at `com.appomatrix.crm`. You own store listing, legal, and marketing site.

## Google Play Console

- [ ] Pay $25 developer account (if not done)
- [ ] Create app → **Appomatrix CRM**
- [ ] Upload **AAB** (`flutter build appbundle --release`) with **release keystore**
- [ ] Store listing: title, short description, full description (voice-first, local privacy)
- [ ] Screenshots: Today, Contacts, Customer detail, Voice note (phone frames)
- [ ] Feature graphic 1024×500
- [ ] Category: Business
- [ ] Privacy policy URL → host [PRIVACY_POLICY.md](../PRIVACY_POLICY.md) on your site or GitHub Pages
- [ ] Data safety form: **No data collected** / on-device only (match actual build)
- [ ] Content rating questionnaire
- [ ] Internal testing → closed testing → production (staged rollout 10%)

## Landing page (VPS)

- [ ] Domain + HTTPS (Let’s Encrypt)
- [ ] One page: problem, 3 screenshots, Play badge link
- [ ] Support email on page and in Play listing

## Launch day

- [ ] Post in same Phase 0 groups (follow group rules)
- [ ] Pin message: free, local, Android only
- [ ] Monitor Play reviews first 48h

## Not in Phase 3 (later)

Cloud sync, payments, team features — see [Phase 5](../phase-5/MONETIZATION_AND_BACKEND.md).
