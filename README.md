# Appomatrix CRM (`appocrm`)

Voice-first, privacy-safe, mobile CRM for solo business owners.

**Product plan:** [docs/APPOMATRIX_CRM_PLAN.md](docs/APPOMATRIX_CRM_PLAN.md)

**Current phase:** MVP app code in `lib/` — run on Android: `flutter run`.

**Validation (optional):** [Phase 0](docs/phase-0/README.md)

## MVP features

- Local SQLite contacts (manual + phone book import)
- One-tap call log, WhatsApp, and phone dial
- Voice notes with on-device speech-to-text
- **Today** tab: follow-ups due now
- Pipeline: Lead → Follow-up → Confirmed → Paid
